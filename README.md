# مصاريف المكتب

سجل عربي بسيط لمصاريف المكتب المشتركة. يعمل بالكامل كصفحة ثابتة على GitHub Pages؛ تُضمَّن بيانات السجل في البناء ولا يطلب الموقع أي واجهة برمجية.

## التشغيل محليًا

```bash
npm install
npm run dev
```

للتأكد من صحة المنطق والبناء:

```bash
npm test
npm run build
```

## إضافة مصروف

من الموقع، اضغط **إضافة مصروف**، أكمل الحقول، ثم اختر **إرسال عبر GitHub**. سيفتح طلب GitHub مُعبّأ بالبيانات؛ بعد إرساله، يتحقق Action من الطلب ويضيف ملف JSON جديدًا. يظهر الإدخال بعد اكتمال بناء Pages، عادةً خلال دقيقة أو دقيقتين.

إذا لم يكن لديك حساب GitHub، استخدم زر **نسخ** وأرسل البيانات إلى الشخص الذي يدخل المصروفات.

## تسجيل دفعة (تسديد)

عندما يسدّد أحدهم لآخر — مثلًا دفع أبو عبيدة ٢٥ لأحمد — سجّل ذلك حتى يعرف الجميع ما تبقّى على كل شخص.

أسهل طريقة: تحت جدول الأسبوع تجد **التسوية المقترحة**، وهي أقل عدد من التحويلات التي تصفّر حسابات الأسبوع. اضغط **تسجيل** بجانب أي تحويل، فيفتح النموذج معبّأً بالدافع والمستلم والمبلغ والتاريخ. أو اضغط **تسجيل دفعة** أسفل الصفحة وأدخل البيانات يدويًا.

عمود **سدّد** في جدول الأسبوع يعرض ما دفعه الشخص للآخرين ناقص ما استلمه، وعمود **الصافي** يجمع كل شيء: موجب يعني له عند المكتب، وسالب يعني عليه.

> **انتبه إلى التاريخ.** الحسابات تُجمع أسبوعًا بأسبوع، فالدفعة تُحسب ضمن أسبوع تاريخها هي. إن سدّدت اليوم دَينًا من الأسبوع الماضي، عدّل التاريخ ليقع داخل ذلك الأسبوع، وإلا لن يُلغِ الدفعُ الدَّينَ. أزرار **تسجيل** في التسوية المقترحة تضبط التاريخ الصحيح تلقائيًا.

الدفعة تُسجَّل كما هي دون التحقق من مطابقتها للمبلغ المستحق، فالزيادة والنقصان كلاهما مقبول.

## تصحيح إدخال

لا يوجد تعديل أو حذف داخل الموقع عمدًا. لتصحيح إدخال، افتح ملفه في [`data/entries`](data/entries) — أو [`data/payments`](data/payments) للدفعات — على github.com وعدّل ملف JSON المناسب مباشرة، ثم احفظ التعديل. يدفع GitHub البناء تلقائيًا ويحدّث الموقع.

كل ملف يجب أن يطابق القواعد في `PROJECT_SPEC.md`: مبلغ صحيح موجب بالليرة السورية (بلا كسور عشرية)، معرفات أعضاء ثابتة، وأسماء مشاركين فريدة. في ملفات الدفعات، يجب أن يختلف `from` عن `to`.

ملف غير مطابق يوقف بناء الموقع، لذلك تحقق من الصيغة قبل الحفظ.
