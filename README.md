# مصاريف المكتب

سجل عربي لمصاريف المكتب المشتركة على [office.ahmadjz.tech](https://office.ahmadjz.tech). الواجهة React، والبيانات في PocketBase على الخادم نفسه. كل عضو يدخل بحسابه.

## الدخول

يعطيك المسؤول اسم مستخدم وكلمة مرور. إن نسيت كلمة المرور فاطلب من المسؤول تعيين كلمة جديدة.

## إضافة مصروف

اضغط **إضافة مصروف**، اختر من دفع ومن شارك، واكتب الغرض والمبلغ، ثم **حفظ**. يظهر الإدخال فورًا عند الجميع، ومعه اسم من سجّله.

## تسجيل دفعة (تسديد)

تحت جدول كل أسبوع تجد **التسوية المقترحة**: أقل عدد من التحويلات التي تصفّر حسابات الأسبوع. اضغط **تسجيل** بجانب أي تحويل فيُعبّأ النموذج بالدافع والمستلم والمبلغ والتاريخ. أو اضغط **تسجيل دفعة** أسفل الصفحة وأدخلها يدويًا.

عمود **سدّد** يعرض ما دفعه الشخص للآخرين ناقص ما استلمه، و**الصافي** يجمع كل شيء: موجب يعني له عند المكتب، وسالب يعني عليه.

> **انتبه إلى التاريخ.** الحسابات تُجمع أسبوعًا بأسبوع، فالدفعة تُحسب ضمن أسبوع تاريخها. إن سدّدت اليوم دَينًا من أسبوع سابق، اجعل التاريخ داخل ذلك الأسبوع، وإلا لن يُلغِ الدفعُ الدَّينَ. أزرار **تسجيل** في التسوية المقترحة تضبط التاريخ تلقائيًا.

## الأرشيف

تظهر الأسابيع الثلاثة الأخيرة فقط، والأقدم في **الأرشيف** أسفل الصفحة. الأسبوع القديم الذي لم تُسوَّ حساباته يبقى ظاهرًا مع علامة **غير مسوّى** حتى يُسدَّد.

## للمسؤول

- **تعديل أو حذف** أي سجل من الأيقونتين على بطاقته.
- **الأعضاء** من القائمة أعلى الصفحة: إضافة عضو، تعديل الاسم، إعادة تعيين كلمة المرور، تعطيل أو تفعيل. العضو لا يُحذف أبدًا؛ المعطّل لا يستطيع الدخول وتبقى سجلاته كما هي.
- لوحة PocketBase على [`/_/`](https://office.ahmadjz.tech/_/) للطوارئ والنسخ الاحتياطية فقط. لا تعدّل بنية الجداول من هناك؛ التعديلات تمر عبر `pocketbase/pb_migrations/`.

## التطوير

```bash
npm install
npm run test:pb     # مرة أولى: ينزّل PocketBase إلى .pb-bin/ ويختبر قواعد الخادم
npm run pb:dev      # PocketBase محلي على 127.0.0.1:8090
npm run dev         # الواجهة، وتمرّر /api و/_ إلى PocketBase المحلي
npm test
npm run build
```

كل دفع إلى `main` يختبر ويبني ثم ينشر الواجهة والـ migrations والـ hooks إلى الخادم. إعداد الخادم في مستودع `ahmadjz/vps-infra`.

`PROJECT_SPEC.md` هو المرجع لكل القواعد.
