# مصاريف المكتب

سجل عربي بسيط لمصاريف المكتب المشتركة. يعمل بالكامل كصفحة ثابتة على GitHub Pages؛ تُضمَّن بيانات السجل في البناء ولا يطلب الموقع أي واجهة برمجية.

## التشغيل محليًا

```bash
npm install
npm run dev
```

للتأكد من صحة المنطق والبناء:

```bash
npm test
npm run build
```

## إضافة مصروف

من الموقع، اضغط **إضافة مصروف**، أكمل الحقول، ثم اختر **إرسال عبر GitHub**. سيفتح طلب GitHub مُعبّأ بالبيانات؛ بعد إرساله، يتحقق Action من الطلب ويضيف ملف JSON جديدًا. يظهر الإدخال بعد اكتمال بناء Pages، عادةً خلال دقيقة أو دقيقتين.

إذا لم يكن لديك حساب GitHub، استخدم زر **نسخ** وأرسل البيانات إلى الشخص الذي يدخل المصروفات.

## تصحيح إدخال

لا يوجد تعديل أو حذف داخل الموقع عمدًا. لتصحيح إدخال، افتح ملفه في [`data/entries`](data/entries) على github.com وعدّل ملف JSON المناسب مباشرة، ثم احفظ التعديل. يدفع GitHub البناء تلقائيًا ويحدّث الموقع.

كل ملف يجب أن يطابق القواعد في `PROJECT_SPEC.md`: مبلغ صحيح موجب بالليرة السورية، معرفات أعضاء ثابتة، وأسماء مشاركين فريدة.
